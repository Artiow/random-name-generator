# Random Name Generator

A tiny static random-name generator for GitHub Pages.

It generates names in the `adjective_surname` format using the adjective and surname lists from the Moby names generator.

## Run

No build step or dependencies are required. Serve the repository as static files or enable GitHub Pages from the repository root.
